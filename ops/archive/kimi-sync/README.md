# Архив: синхронизаторы Kimi→ZCode

Схемы «канон в Kimi, ZCode-копия генерируется» больше нет: с 24.10.2026 ZCode —
основа, скилы правятся руками в `~/.zcode/skills/`, глобальные правила — в
`~/.zcode/AGENTS.md`. `~/.kimi-code/` — замороженный архив оригиналов.

- `sync_skills_zcode.py` — генерил `~/.kimi-code/skills/` → `~/.zcode/skills/`
  (whenToUse→when_to_use, ${KIMI_SKILL_DIR}→абсолют). Переписывания пригодятся,
  если Kimi вернётся в строй и понадобится обратный перенос из ZCode-канона.
- `sync_agents_zcode.py` — то же для глобальных правил (REWRITES с жёстким
  фейлом при рассинхроне).

Не запускать: оба пишут из устаревшего канона и затрут ZCode-оригиналы.

Обновление 25.10: Kimi возвращён в строй владельцем; обратный генератор — ops/kimi_sync_back.py (канон остаётся ~/.zcode).
