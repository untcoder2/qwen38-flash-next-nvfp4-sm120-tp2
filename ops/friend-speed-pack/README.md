## 2. Effort без ручного селектора — ОДИН кусок в config.toml

Дайджест идеи: субагенты по умолчанию на medium (быстрые руки), xhigh — только
когда главный агент сам явно позовёт. Без этого **все** субагенты наследуют
усилие главной сессии = переплата на рутине.

```toml
# вариант той же модели на medium (запиши ПОЛНО, поля не наследуются)
[models."local/<твоя-модель>-fast"]
provider = "<твой provider>"
model = "<та же model>"
max_context_size = <тот же>
capabilities = [ "tool_use", "thinking" ]
support_efforts = [ "low", "medium", "xhigh" ]

[models."local/<твоя-модель>-fast".overrides]
default_effort = "medium"

[secondary_model]
default_model = "local/<твоя-модель>-fast"

[secondary_model.models]
"local/<твоя-модель>" = "xhigh: hard debugging, audits, root-cause — explicitly."
"local/<твоя-модель>-fast" = "medium: routine ops. Default for subagents."
```

Важно: секционная строка `default_effort` внутри `[secondary_model]` **перебивает**
уровень любой записи пула — если она есть, удали. Main-сессию не понижай, если
не уверен: пусть остаётся xhigh, пул съэкономит на деллегатах.

## 3 + 6. Вывод по умолчанию маленький — кусок в AGENTS.md (глобальный или проектный)

```md
Локальные Grep/Glob всегда с head_limit (по умолчанию 20, не 100) и фильтром
`glob: "!{<датасеты>,tmp}/**"`. Хостовые/длинные команды — сразу `| tail -N` /
`grep -m N`; полный вывод нужен целиком — в файл, не в ленту. Весь вывод тулз
идёт агенту в контекст: раздутый ответ = ре-префилл и тормоза на следующих ходах.
```

## 4. Серии удалённых команд — одним скриптом, не N вызовами

Скрипты в этой папке: `rsh.sh` (одна команда) и `runsh.sh` (локальный скрипт хосту за
один round-trip, аргументы+exit-код). Цели задаются окружением, секретов нет:

```bash
export RSH_HOST=user@host RSH_KEY=~/.ssh/ваш_ключ
```

Дисциплина та же: независимые вызовы параллельно в одном ходе; всё дольше минуты
— фоном.

(«Failed to connect to new control master», Win32-эмуляция AF_UNIX). Не ставь.
