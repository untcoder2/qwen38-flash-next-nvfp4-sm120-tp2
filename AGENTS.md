# AGENTS.md — D:\llm

Рабочий каталог LLM-инфраструктуры. Стек и журнал: [docs/architecture.md](docs/architecture.md),
[docs/notes.md](docs/notes.md). Сам сервер — удалённый хост `molochko@192.168.2.127`
(SGLang-инфер :1234); здесь только заметки, конфиги-зеркала и скрипты из `ops/`.

## Где что исполняется

- **Локально (Windows):** работа с этим каталогом — Read/Write/Edit/Grep/Glob, git,
  правки зеркал конфигов, заметки. Локальные Grep/Glob всегда с фильтром
  `glob: "!{corpus,tmp}/**"`: датасеты и временные деревья не грепаем (урок 14.10 —
  поиск двух строк в notes притащил 1.3 МБ цитат из корпуса).
- **На хосте, только через `ops/rsh.sh`:** nmap, hashcat, ffuf, сканы целей
  (`pentest-xiaomievparts/`), долгий curl/нагрузочные прогоны, компиляция, всё, что
  ест GPU/CPU или лезет в сеть целевой подсетью. Не запускать эти тулзы на Windows.

Обёртки (ключ `~/.ssh/molochko_deploy`, BatchMode, exit-код пробрасывается):

```bash
ops/rsh.sh 'nmap -sV 10.0.0.5'                    # команда на хосте (bash -lc)
ops/runsh.sh ops/_probe.py [args]                 # ЛОКАЛЬНЫЙ скрипт хосту, один round-trip
ops/rput.sh ops/_probe.py                          # файл -> ~/agent-tools/ на хосте
ops/rget.sh /home/molochko/agent-tools/out.json    # отчёт оттуда
```

Дисциплина round-trip'ов (14.10): серию хостовых команд писать ОДНИМ скриптом
через `runsh.sh`, а не N вызовами `rsh.sh` — транспорт по LAN дешёвый (~0.2 с),
дороги сами вызовы; независимые вызовы — параллельно в одном ответе; всё дольше
минуты — фоном. Незачем батчить вывод: `journalctl`/снепшоты сразу резать
`tail`/grep на хосте.

Дисциплина вывода (14.10): весь вывод тулз идёт мне в контекст — большой ответ
это ре-префилл и медленный следующий ход. Локальные Grep/Glob всегда с
`head_limit` (по умолчанию 20, не 100) и фильтром `glob: "!{corpus,tmp}/**"`;
хостовые команды — сразу с `| tail -N` / `grep -m N` на хосте; полный вывод то
нужен целиком — писать в файл на хосте и забирать `rget`, а не лить в ленту.

Рабочие скрипты агента на хосте живут в `~/agent-tools/`, их зеркала — в `ops/`
(существующая практика проекта).

## Правила безопасности на боевом хосте

- Хост обслуживает инфер, на котором работают текущие агентные сессии. Любая
  нагрузка (hashcat, сканы, сборки) конкурирует с генерацией — держать это в уме
  и не выкручивать параллелизм «в пол».
- **Не трогать** `sglang.service`, `vllm-watchdog`, `active.cfg` и не рестартовать
  ничего без явного спроса владельца. Рестарт sglang — только NOPASSWD-команда из
  sudoers; ручной запуск листов через setsid запрещён (см. notes 19.09).
- **Жёсткий стоп по необратимому:** рестарт, смена флагов запуска, откат снапшота —
  исполняются только после отдельного явного «да» владельца именно на этот шаг,
  а не «в пакете» с общим решением (урок 27.09: «сделай 1M» не означает
  «рестарти прямо сейчас»). Отменимое до этого момента — чинить отменой нельзя.
- Работы в `~/vllm` — сначала `touch /home/molochko/vllm/.maintenance` (watchdog
  засыпает), после выхода в READY — снять.
- hashcat — только через обёртку `/home/molochko/bin/hashcat-nvrtc` (CUDA-библиотеки,
  `-w 2`, keepfree уже вшиты).
- `sudo` на хосте **с паролем**, NOPASSWD разрешены только конкретные systemctl-юниты.
  Не придумывать команд, требующих root: либо они в списке, либо спрашивать владельца.
- docker: `image prune -a` запрещён (rollback-теги, см. docs/rollback.md); перед
  апдейтом образа — свежий `snapshot.py --pin`.

## Префиксный кеш: не дёргать system-префикс при живых сессиях

Radix-кеш инфера стоит на стабильном начале промпта. Любая правка AGENTS.md (корень
и `~/.kimi-code/AGENTS.md`), `.agents/skills/` и `.agents/agents/`,
`~/.kimi-code/skills/`, `~/.kimi-code/config.toml` при работающих агентских сессиях
сбрасывает их префикс → полный ре-префилл истории (замерено: тёплый ход ~1K uncached,
холодный ~90K). Поэтому: такие файлы правим только когда живых сессий нет, пачкой,
или сразу после — новой сессией; `.agents/agents/` и `ops/hooks/` к тому же под
guard-DENY (доставка shell/python по явному «да»). Проверка хита за окно, а не с
момента рестарта: `ops/rsh.sh 'python3 -I ~/agent-tools/cache_window.py 60'`
(зеркало ops/cache_window.py; дашбордные проценты — кумулятив с последнего рестарта
инфера, он врёт первые часы). Наследие эпохи Claude Code (`.claude/settings.json`,
`CLAUDE_CODE_ATTRIBUTION_HEADER`) больше не носитель префикса — CLI снесён, файлы
остались как архив; плато хита 14.10 остаётся необъяснённым (notes 14.10).
